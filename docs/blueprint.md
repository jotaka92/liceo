# **App Name**: EduEspacio

## Core Features:

- Welcome Section: Display a welcome message in Spanish, including the institute's name and a brief introduction.
- Course Listing: Show a list of available courses or programs with brief descriptions and links for more details. All content is in Spanish.
- Contact Information: Include a contact section with the institute's address, phone number, email, and a contact form. All labels and instructions in Spanish.

## Style Guidelines:

- Primary color: Blue (#3498db) to convey trust and stability.
- Secondary color: Light gray (#ecf0f1) for backgrounds and subtle contrasts.
- Accent: Orange (#e67e22) for buttons and important links.
- Use a clean, responsive layout to ensure the website looks good on all devices.
- Employ simple, professional icons to represent different sections or types of information.
- Incorporate subtle hover effects on interactive elements to improve user engagement.
